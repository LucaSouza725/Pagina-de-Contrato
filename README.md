# Página de Contrato

A 'Página de Contrato' é um trabalho de faculdade contando como avaliação P1 do semestre

## Formulario

formulario.html é o primeiro exercício de fato da lista, onde separamos oque desenvolvimento com oque é Produção. No caso, formulário servirá para fazer a coleta de 3 dados: Nome, Email e Telefone, será feito em 2 commits diferentes, o primeiro sendo o HTML puro e o segundo um CSS básico.
